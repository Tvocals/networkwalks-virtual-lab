## 1. Introduction and Project Overview

During the first week of my cybersecurity internship at Networkwalks, I was assigned the task of setting up a virtual laboratory environment for practical cybersecurity exercises.

The objective of this exercise was to establish a controlled environment where I could perform network-related activities, security assessments, and other authorized penetration testing exercises.

This exercise provided a practical introduction to virtualization, Linux system administration, and basic network configuration. The virtual laboratory will serve as the foundation for subsequent cybersecurity practicals throughout the internship.

## 4. Implementation and Configuration Process

### Step 1: Installation of Oracle VirtualBox

I began by installing Oracle VirtualBox on my host computer.

Oracle VirtualBox is a virtualization platform that allows users to create and operate multiple virtual machines on a single physical computer.

It provides the ability to run different operating systems independently without requiring additional physical hardware.

### Step 2: Creation and Installation of Kali Linux Virtual Machine

After installing VirtualBox, I created a new virtual machine and configured it to run Kali Linux.

Kali Linux is a Debian-based Linux distribution designed for penetration testing, vulnerability assessment, digital forensics, and other cybersecurity activities.

I completed the installation and initial configuration of the operating system, ensuring that the virtual machine was ready for network configuration and subsequent practical exercises.

### Step 3: Virtual Network Configuration Using NAT Network

I configured the network adapter of the Kali Linux virtual machine to use NAT Network mode.

NAT Network allows virtual machines connected to the same virtual network to communicate with one another while accessing external networks through Network Address Translation (NAT).

This configuration provides a suitable environment for conducting controlled network experiments and testing communication between virtual machines.

### Step 4: Static IP Address Configuration

I proceeded to configure a static IP address for the Kali Linux virtual machine.

A static IP address is manually assigned to a network interface and remains consistent unless it is changed by the administrator.

During this process, I identified the active network interface and configured the required network parameters, including:

- IP Address
- Subnet Mask or Prefix Length
- Default Gateway
- DNS Server

The purpose of this configuration was to ensure that the Kali Linux virtual machine maintained a consistent network identity, making it easier to identify and access during subsequent laboratory exercises.

### Step 5: Network Configuration and Laboratory Preparation

After configuring the network settings, I prepared the virtual laboratory for upcoming cybersecurity activities.

The configuration was intended to provide a foundation for communication between virtual machines, network discovery, reconnaissance, and other authorized security testing exercises.

Network connectivity and configuration parameters are important aspects to verify before proceeding with practical network assessments.

## 7. Next Phase: Network Reconnaissance

Having established the virtual laboratory environment, the next phase of the internship will focus on network reconnaissance.

Network reconnaissance involves gathering information about a target network to identify active hosts, discover open ports, determine running services, and understand the network's structure.

The planned activities include:

1. **Host Discovery:** Identifying active devices within the authorized laboratory network.
2. **Port Scanning:** Discovering open ports on identified hosts.
3. **Service Enumeration:** Identifying services and applications running on discovered ports.
4. **Operating System Identification:** Gathering information about the operating systems running on target machines.
5. **Result Analysis:** Examining reconnaissance findings to identify potential security weaknesses and areas requiring further investigation.

All reconnaissance and testing activities will be performed within the authorized virtual laboratory environment.

These configurations will also be important when introducing additional virtual machines into the laboratory for future practical exercises.
